33OJ 成绩分析器

输入一个 UID，自动抓取该用户在 33OJ 任意数据域、任意年份的比赛成绩， 输出平均分、排名、月度趋势、题位表现，并支持多人横向对比与报告导出。

打开分析器 → GitHub 仓库 使用文档

它能做什么

📊

总览统计

参赛场次、参赛率、总分、平均分（三种口径）、中位数、标准差、最高最低分、零分场次。

🏆

排名分析

平均排名、最好最差名次、平均击败率、每场与全场平均分的差值。

📅

多年份

支持 2024-2026、all 等写法，给出分年份 × 分用户的平均分对照与柱状图。

📈

月度趋势

按月统计场次与平均分，一眼看出进步或滑坡。

🎯

题位表现

把各场比赛的 T1/T2/… 对齐，算出「相对全场」倍率，定位强项与弱项。

📥

报告导出

一键下载 Markdown 报告与逐场明细 / 每题得分 / 汇总 CSV。

两种用法

A. 本地运行（推荐，功能最全）

本机跑一个零依赖的 Node 服务，图形界面直接开在浏览器里。会话从你本机已登录的 Edge 自动获取， 不用手动填任何凭据。 

git clone https://github.com/WangNoNo666/33oj-score-analyzer.git
cd 33oj-score-analyzer
start-edge.cmd      :: 启动一个带调试端口的 Edge，登录一次
启动-OJ成绩分析器.cmd  :: 打开图形界面

B. 在线部署（服务器端抓取）

把后端部署到任何支持 Docker 的平台（Render / Railway / Fly.io…）， 前端可以继续放在 GitHub Pages 上。 

# 平台会读取仓库里的 render.yaml / fly.toml / railway.json
# 关键环境变量：
OJ_MODE=cloud
OJ_ALLOW_ORIGIN=https://wangnono666.github.io
部署完把 OJ_ALLOW_ORIGIN 改成你的前端地址；前端也可以用 ?api=https://你的后端 直接指定后端。

安全说明

本站没有服务器保存你的任何凭据。在线模式只做一件事： 拿你填的 Cookie 去请求 oj.33dai.cn，请求结束即丢弃，不写磁盘、不记日志 （异常信息里的 Cookie 也会被打码）。页面侧只放在 sessionStorage，关掉标签页就没了。
但请注意：Cookie 等同于你的登录凭证。填给任何第三方服务之前都应该想清楚 —— 更稳妥的做法是本地运行。用完随时可以在 OJ 上退出登录让 Cookie 失效。

实现要点

  • 零第三方依赖：只用 Node 内置模块，不需要 npm install。
  • 会话获取：33OJ 是私有域，且 Edge 用 App-Bound Encryption 保护 Cookie， 磁盘上的 Cookie 复制到别的配置目录也解不开 —— 所以通过 DevTools 协议向运行中的 Edge 索取。
  • 自适应限流：OJ 在请求过快时会返回 403。客户端会匀速放行、识别突发 403 并指数退避， 同时区分「真被限流」和「这张成绩表本来就锁着」，避免统计结果悄悄少算比赛。
  • 年份归属：优先用 beginAt；时间戳年份不在所选范围内但标题含该年份时按标题兜底并标注 （OJ 上确实存在把 2026 录成 2036 的比赛）。
  • 界面：原生 HTML/CSS/JS + SVG 图表，同一套代码既能被后端托管，也能单独部署到 Pages。

数据来源

数据全部来自 oj.33dai.cn（33OJ，Hydro 内核）。 本项目只是把公开可读的成绩页面整理成便于分析的报表，不存储、不传播任何用户数据。
